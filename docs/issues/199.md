## Triage decisions (2026-10-09)

- The caps stay. `//`: two lines. `///`: one paragraph of at most eight
  lines, or a summary of at most two and one paragraph of at most six.
  Three-line `//` runs are in scope.
- Exempt: `//!` module docs; fenced code and table rows, which do not count.
- An RFC quote is cut to the clause that carries the claim; the section
  number stays.
- A cut design argument that is hard to reverse, surprising and a real
  trade-off becomes an ADR, linked from the comment; anything else goes to
  the commit message.
- Test code is in scope, as each crate's last commit.
- The limits and the script landed in `CLAUDE.md` "Writing comments" before
  the sweep.
- Done is not zero: each block left over the cap is listed with its reason
  in the closing note.

## Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Cut every comment over the "Writing comments" caps to the
reason it carries, crate by crate.

**Current behavior:** `python tools/comment_caps.py` reports 791 blocks
over in code and 503 in tests.

**Desired behavior:**
- Each block over the cap keeps the one reason a reader needs; elaboration,
  derivations and second examples go. Nothing current and load-bearing is
  lost: a design argument meeting the ADR bar moves to `docs/adr/` (next
  number, format of `0001`-`0008`), the comment keeping one line and the
  link; the rest goes to the commit message.
- Where an ADR already holds the argument (`0002` and `dname.rs`), the
  comment links it and the ADR stops pointing back at the comment for it.
- Order, one commit per crate and region, code before test: `rdns-tsig`,
  `rdnsc`, `rdns-present`, `rdns-transport`, `rdnsr`, `rdns-core`, `rdnsd`,
  `rdns`.

**Acceptance criteria:**
- [ ] Each commit states the crate's count before and after.
- [ ] No code changes: `git diff -w` outside comments and `docs/` is empty.
- [ ] `cargo fmt --all`, `cargo clippy --workspace --all-targets`,
      `cargo doc --workspace --no-deps` clean per commit; Linux clippy and
      doc for a crate with `cfg(unix)` files.
- [ ] Each new ADR named in the commit that adds it.
- [ ] Closing note: the script's final table, and every block still over
      with its reason.

**Out of scope:** `//!` module docs; rewording comments within the caps;
`CLAUDE.md` and `docs/LESSONS.md` (#200).
