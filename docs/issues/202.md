- Trigger: `workflow_dispatch`, no inputs; runs `./run.sh all`.
- Every peer image pinned exactly: `cznic/knot:v3.6.0` (both services),
  BIND by digest (`internetsystemsconsortium/bind9:9.20@sha256:...`; the image
  publishes no patch tags), the peers image `FROM alpine:3.22.6`. ~~NSD and
  Unbound packages float within 3.22~~ **Wrong: `Dockerfile.peers` pinned
  every package revision, and the pins were already broken** (Unbound

  The decision stands on the reason given for it: pinning `apk` revisions
  breaks when Alpine drops them, so the pins are removed, and pinning the

  against.
- `skip()` and the `SKIP` counter are deleted (no caller).

**Category:** enhancement
**Summary:** Run the interop harness from a manually dispatched workflow,
against pinned peers.

**Current behavior:** `tests/interop/run.sh all` runs only by hand on a Linux
host with Docker. `report` returns 1 on any FAIL and `all` ends with it.
Knot floats on `latest`, BIND on `9.20`.

**Desired behavior:**
- A `workflow_dispatch` workflow on `ubuntu-latest` that runs
  `tests/interop/run.sh all` and fails exactly when it does.
- The job summary carries the pass/fail counts, the failed assertion names,
  and the peer versions `versions` prints.
- On failure, `docker compose logs` for every service is uploaded as an
  artifact.
- Peer images pinned as decided above; the BIND digest is the one current
  when the work is done, and the commit names the version it resolves to.
- `skip()` and `SKIP` removed from the harness and its report.

- [ ] `run.sh all` passes locally on Linux with the pins, platform stated.
- [ ] `grep -rn latest tests/interop/` finds no image reference.
- [ ] The workflow parses (`actionlint`, or the reason it cannot run).
- [ ] The commit records the local wall-clock time of `run.sh all`, cold and
      warm image cache, as the cost estimate for a hosted run.

**Out of scope:** running on push or schedule; new scenarios; changing
assertions.
