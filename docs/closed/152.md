#### Agent brief

**Category:** enhancement
**Summary:** The re-signing interval comes back with the rule that chose it,
and the startup line is built from that alone.

**Current behavior:** `ZoneSigning::resign_interval_at` computes the ordinary
interval (`resign_after` of the shortest validity, floored at a minute) and the
time to the next key transition (#44f), and returns the smaller as a
`Duration`. The startup line recomputes the ordinary interval to decide which
reason to print, and spells the fraction as "a third".

**Desired behavior:** the interval is returned together with its reason —
the ordinary rule, carrying the validity it is a fraction of, or the next key
transition. The startup line reads both from that value and calls nothing in
`zone_signer`. Its wording is produced from the reason in one place that a
test can call, and either derives the fraction from `RESIGN_FRACTION` or does
not name it. The maintenance loop's sleep uses the interval as now.

**Key interfaces:**
- `ZoneSigning::resign_interval` / `resign_interval_at`: return the interval
  and its reason rather than a bare `Duration`.
- `zone_signer::resign_after` and `RESIGN_FRACTION`: unchanged, and named by
  nothing in `rdnsd` outside `ZoneSigning`.

**Acceptance criteria:**
- [ ] The existing `resign_interval_at` tests also assert the reason —
      ordinary for no key change, a distant one or a finished one;
      key transition for a near one, including the one-minute floor.
- [ ] A test of the wording for two different shortest validities, showing
      the sentence follows the validity and the fraction.
- [ ] `grep` finds no `resign_after` in `rdnsd` outside `ZoneSigning`'s
      implementation and its tests.
- [ ] Workspace tests and clippy pass on Windows and Linux; fmt and doc
      clean.

**Out of scope:**
- The interval arithmetic, the one-minute floor, the one-second step past a
  transition, and `RESIGN_FRACTION`'s value.
- What the re-signing run does when it fires.
